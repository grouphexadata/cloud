# Standard Repository Structure

## Mandatory tree

```
/src
/tests
/docs
/examples
/.github
README.md
LICENSE
CONTRIBUTING.md
CHANGELOG.md
```

## Recommended optional tree

```
/scripts
/config
/assets
```

## Minimum quality controls
- CI on pull request
- branch protection on main
- CODEOWNERS
- secret scanning
- dependabot alerts enabled

# Contributing Guide

## Branching model
- main: rama estable
- feature/*: nuevas capacidades
- fix/*: correcciones
- chore/*: tareas operativas

## Commit convention
Formato:
- feat: descripcion
- fix: descripcion
- docs: descripcion
- refactor: descripcion
- test: descripcion
- chore: descripcion

## Pull Request checklist
- cambio acotado y con objetivo claro
- tests actualizados o justificacion
- sin secretos en codigo ni historial
- documentacion actualizada si cambia comportamiento
- aprobacion de al menos 1 reviewer

## Security checks
- no hardcodear credenciales
- usar variables de entorno
- validar entradas externas
- aplicar principio de minimo privilegio

## Definition of done
- codigo revisado
- pruebas pasando
- changelog actualizado
- compatibilidad verificada

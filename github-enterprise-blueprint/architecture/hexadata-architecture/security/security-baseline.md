# Security Baseline

## Requerimientos minimos
- 2FA obligatorio en organizacion
- branch protection en main
- secret scanning habilitado
- dependency alerts habilitadas
- least privilege en tokens y workflows

## Hardening de repos
- CODEOWNERS
- required reviewers
- signed commits recomendado
- no secretos en repositorio

## AppSec minimo
- SAST en PR
- escaneo de dependencias
- politicas de respuesta a incidentes

## Cumplimiento
- clasificacion de datos
- trazabilidad de cambios
- retencion y auditoria de logs

# Development Standards

## Naming
- repositorio: hexadata-[dominio]
- servicios internos: [dominio]-svc-[contexto]
- ramas: feature/*, fix/*, chore/*

## Versioning
- semantic versioning (MAJOR.MINOR.PATCH)
- breaking changes requieren major

## Testing
- unit tests obligatorios
- integration tests en componentes core

## CI/CD
- build, test, lint en pull request
- release con tag firmado

## Documentation
- README actualizado en cada modulo
- changelog por version
- ADR para decisiones criticas
